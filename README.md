# Gofasst Cargo Management

A phone-friendly installable web app (PWA) for Gofasst Shipping and Logistic LLC.

## Publish with GitHub Pages
1. Upload **all files in this folder** to the root of the `Gofasst--Cargo` repository (same level as this README).
2. In GitHub, open the repository **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish. Open the website URL in Safari on iPhone.
6. In Safari tap Share → Add to Home Screen → Add.

## Included
- Dashboard and cargo revenue / payments / customer balances / estimated profit
- Multiple container records
- Cargo charged by kg, cubic feet, or fixed-price units
- Editable rates and container costs
- CSV export and full JSON backup / restore
- Offline support after the first online visit

## Starting assumptions loaded
- Shipping: $8,100
- Customs, duties, port fees and unloading: $14,000
- Total baseline cost: $22,100
- Target: 20,000 kg
- Standard rate: $2/kg
- Recommended rate: $2.25/kg

Data is stored locally in the browser on the device. Export backups regularly. This starter version does not synchronize records between different phones.
